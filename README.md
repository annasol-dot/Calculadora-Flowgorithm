# Calculadora-Flowgorithm

Uma calculadora om 18 funções, projetada a partir de um fluxograma do Flowgorithm. O Sistema possui uma menu interativo oferecendo 18 funções matemáticas organizadas e estruturadas.
---
# Funcionalidades
- Operações Básicas:
   - 1.Adição
   - 2.Subtração
   - 3.Multiplicação
   - 4.Divisão
   - 5.Potência
   - 6.Raíz Quadrada
   - 7.Raíz Cúbica
   - 8.Porcentagem
- Calculo de área e cirunferência:
   - 9.Circunferênia
   - 10.Área Trapézio
   - 11.Área Círculo
   - 12.Área Triângulo
   - 13.Área Losango
-Logarítimo
   - 14.Logaritimo
- Conversor de Temperatura
   - 15.Celsius - Fahrenheit
   - 16.Celsius - Kelvin
- Média
   - 17.Média Aritimética
- IMC
  - 18.IM
